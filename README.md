# Ore Burst — Issue Tracker

Use this repository to report bugs, suggest features, or share feedback for **Ore Burst** (Minecraft 26.3, Fabric).

## Before Opening an Issue
- Make sure you are running **Ore Burst `1.0.0`** on **Minecraft 26.3 (Fabric)** with **Fabric API** installed on both client and server.
- Check existing open or closed issues first to see if the problem has already been reported.

## Reporting a Bug
Please include the following details so the issue can be reproduced quickly:
1. **Minecraft & Fabric version** (e.g., MC 26.3, Fabric Loader & Fabric API versions)
2. **Environment** (Singleplayer, Multiplayer server, or both)
3. **Steps to reproduce** (what ores, combos, or commands were involved)
4. **Expected vs. actual behavior**
5. **Logs / crash report** (paste relevant logs or attach a file if applicable)

## Feature & Balance Suggestions
Feel free to open an issue for ideas related to:
- Burst and Mega Burst mechanics
- Combo thresholds or bonus drop rates
- Configuration options (`config/oreburst.json`)
- Additional language translations
